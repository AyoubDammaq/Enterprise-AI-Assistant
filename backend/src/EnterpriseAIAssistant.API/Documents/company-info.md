# Enterprise AI Assistant

Enterprise AI Assistant is a software project
designed to demonstrate enterprise AI architecture.

## Architecture

The backend follows Clean Architecture.

The main layers are:
- Domain
- Application
- Infrastructure
- API

## Technologies

The backend uses:
- .NET 10
- C#
- Semantic Kernel
- Ollama
- SQL Server
- PostgreSQL

## AI capabilities

The application supports:
- Conversational AI
- Function Calling
- Retrieval-Augmented Generation (RAG)
- Document indexing and semantic search
