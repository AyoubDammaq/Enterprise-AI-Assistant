# Product Guide — Atlas Inventory

## Product overview

Atlas Inventory is a fictional inventory management application designed for small warehouses.

It allows users to track stock quantities, manage product categories, and review inventory movements.

## Stock alerts

Atlas Inventory generates a low-stock alert when a product quantity falls below its configured minimum threshold.

The default threshold for a newly created product is 10 units.

Warehouse managers can configure a different threshold for each product.

## Inventory reports

The application provides three standard reports:

- Current Stock Report
- Inventory Movement Report
- Low-Stock Products Report

Reports can be exported in CSV format.

## User roles

Atlas Inventory has three roles:

- **Administrator:** manages users, product categories, and application settings.
- **Warehouse Manager:** manages products, stock quantities, and inventory reports.
- **Viewer:** can view product information and reports but cannot modify inventory.

## Data refresh

The dashboard refreshes inventory information every five minutes. Users can also manually refresh the dashboard.
